&#x09;Понятия:

Рабочая папка - текущая папка с файлами проекта, в которой происходят изменения файлов.

Индекс - промежуточный этап, на котором сохраняются изменения проекта для дальнейшего коммита.

Коммит - зафиксированный снимок проекта с его измененными файлами с отправкой в репозиторий.



&#x09;Различия Git и GitHub:

Git - локальная система контроля версий, открывающаяся через консоль, которая нужна чтобы отслеживать и вносить изменения в проекте.

GitHub - облачная платформа где хранятся все репозитории для удобства совместной работы над проектом.



&#x09;Разница diff и diff --staged:

git diff - сравнивает рабочую папку и индекс

git diff --staged - сравнивает индекс и последний коммит



&#x09;Использованные команды:

git status - показывает состояние рабочей папки и индекса

git diff - показывает несохраненные изменения в рабочей папке

git diff --staged - показывает сохраненные изменения в индексе
