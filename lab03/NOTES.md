git diff - показывает разницу между коммитами, построчно

git show - выводит полную информацию о конкретном коммите(автор, дата, изменения)

git log - показывает общую историю коммитов. если написать флаги, то покажет статистику и граф



git log -S"" - ищет в истории проекта в какой момент появилась строчка с фрагментом из кавычек и показывает коммит в котором она появилась

git blame - выводит файл построчно, показывает кто и в какую дату и время закоммитил каждую строчку в файле





git restore - откатывает изменения до последнего коммита. если написать флаг --source=…, то откатит не до последней версии а до той, которая указана после знака равно, заменяя текущую. без этих команд несохраненные локальные правки в проект были бы безвозвратно потеряны при переключении версий.





git revert - создает новый коммит, который отменяет изменения указанного коммита(последнего по умолчанию). git reset --hard - удаляет коммиты и ломает историю, а revert более безопасен для общей истории, т.к. сохраняет все цепочки коммитов целыми и понятными.





tag - неизменяемая метка на конкретный коммит в истории проекта, которая навсегда привязана к тому коммиту, куда его поставили
