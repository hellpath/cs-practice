git diff - показывает разницу между коммитами, построчно

git show - выводит полную информацию о конкретном коммите(автор, дата, изменения)

git log - показывает общую историю коммитов. если написать флаги, то покажет статистику и граф



git log -S"" - ищет в истории проекта в какой момент появилась строчка с фрагментом из кавычек и показывает коммит в котором она появилась

git blame - выводит файл построчно, показывает кто и в какую дату и время закоммитил каждую строчку в файле
